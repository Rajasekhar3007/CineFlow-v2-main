Cineflow requirements

- JDK 21. Confirm that both java -version and mvn -version report Java 21.
- Apache Maven 3.9 or newer, available on PATH.
- MySQL Server 8.0, running locally. MySQL Workbench is optional.
- Internet access on the first Maven build to download dependencies.
  Maven installs JavaFX and the MySQL JDBC driver from pom.xml.

First-time setup

1. For a fresh database, run database/schema.sql and then database/seed_data.sql.
   For an existing database on version 004, apply
   database/migrations/005_cancellation_refunds.sql instead.
2. Copy db.properties.example to db.properties. Set your local MySQL username,
   password, and port. Keep db.properties private.
3. From the folder containing pom.xml, run mvn compile javafx:run.

See TEAM_SETUP.txt for detailed instructions and demo logins.
